2. Most important exchange

The most important exchange between user, System and third parties.

sequenceDiagram
  participant U as User
  participant P as System
  participant T as Third party
  U->>P: sends request
  P->>P: checks conditions
  alt conditions not met
    P-->>U: explains why, does nothing else
  else conditions met
    loop each item
      P->>T: calls processing
      T-->>P: returns result
    end
    P-->>U: shows result
  end
